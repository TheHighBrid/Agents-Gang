# Melato Visual Product Standard

Approved product image standard:
- Centered garment
- Same scale across all products
- Same crop
- Same garment length
- Same sleeve spread
- Same background
- Same shadow softness
- No design/color changes
- Front, back, 45-degree angle, macro close-up

When correcting an image:
- Preserve original garment color
- Preserve design details
- Preserve embroidery
- Preserve proportions
- Only adjust placement, sizing, crop, background, lighting, and sharpness
